## 四、方法摘要

**问题 1（模型建立）**

光程差（含半波损失）→ 双光束干涉光强模型 → 厚度计算公式（常数折射率式 (9)/(10)，非常数折射率式 (11)）→ 反射率模型与包络反演折射率（式 (12)–(24)）。完整推导见文档第 2 节。

**问题 2（SiC 厚度计算）**

1. 剔除剩余射线带，只使用波数 ≥ 1000 cm⁻¹ 的数据；
2. 101 点中心移动平均滤波；
3. 三次样条插值 + 试探区间 + 单变量优化定位波峰/波谷，并用显著性阈值 0.05% 反射率剔除残余噪声产生的伪极值；
4. 波峰/波谷点三次样条插值构造上下包络，反演折射率 $n(\omega)$、$n_s(\omega)$；
5. 在 2000–3800 cm⁻¹ 内取全部峰谷组合（排除 $N=0.5$），按式 (11) 计算厚度，以均值±标准差为结果；
6. 可靠性：理论光谱对比 + 仅波峰/峰谷两口径对照。

**问题 3（多光束干涉与 Si 厚度）**

1. 必要条件：$I_3$ 不可过小，即 $r_{1s}$ 较大、折射率比值达 3 的量级；多次反射不影响波峰坐标但影响波谷坐标；
2. 多光束干涉模型式 (31)–(36) 反演折射率；
3. 硅数据（附件 3、4）出现明显多光束干涉：500–1500 cm⁻¹ 折射率比值 2.66/2.97、峰谷差 70.8%/78.4%；
4. 硅厚度以多光束模型为准；双光束与多光束结果绝对差 0.13–0.15 μm，说明影响不可忽略；
5. 碳化硅多光束复核：折射率与厚度基本不变（差 < 0.001 μm），不受影响、无需修正；
6. 最终结果按逆方差加权合并两组入射角数据并给出 95% 置信区间。

## 六、关键实现细节（学习提示）

1. **噪声伪极值**：101 点滤波后仍残留幅度小于 0.01% 反射率的噪声，三次样条会因此产生“成对”的微小伪极值；若不过滤，厚度会被明显高估（SiC 约 18 μm）。程序使用显著性阈值 0.05% 过滤，真实条纹幅度约 0.4%–1.4%，两者可清晰分离。
2. **硅包络覆盖范围**：硅的第一个厚度极值点位于 1105.28 cm⁻¹，包络必须覆盖 ω ≥ 500 cm⁻¹ 的极值点，否则该处折射率是样条外推值（2.88 而非正确的 3.00），厚度组合会系统偏低。
3. **入射角处理**：折射率反演按正入射简化（0°–40° 内误差很小）；厚度公式式 (11) 保留各自实际入射角（10°、15°）的 $\sin^2\theta_1$ 项。
4. **条纹间隔数**：$N=(j-i)/2$，其中 $i$、$j$ 为峰谷序列序号；排除 $N=0.5$（相邻峰谷）的组合以减少误差。
5. **加权平均**：讲评只说明“两组数据按加权平均”，未给出权重；本项目采用逆方差加权 $w=1/\sigma^2$，并在文档 4.6 节写明公式。
